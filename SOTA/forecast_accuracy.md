# Forecast-accuracy analysis (Paper 4 / WBF)

One-step-ahead forecast accuracy of Facebook Prophet vs. two trivial baselines, measured on the raw CPU time series the simulator forecasts. The simulator itself is untouched.

## Configuration

- History window: **30 steps** (= 150 min at 5-min sampling)
- Horizon: **1 step(s)**, resumed to a scalar by **mean**
- EWMA alpha: 0.5
- MAPE excludes |actual| < 1.0% (avoids divide-by-~0)
- VMs per workload: 100; window stride: 1; cap/VM: none
- Alibaba CPU column: `mem_util_percent`
- Prophet: available
- Prophet invocation identical to `pymodule/forecastingTechniques.py::python_getFacebookProphet` (`Prophet(uncertainty_samples=None)`, fake daily `ds`)
- Bollinger filter (winma=5, alpha=0.5) is a separate WBF component and is intentionally NOT applied here
- Wall-clock: 9101.5 s
